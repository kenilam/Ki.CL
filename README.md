# Setup

## Preparation
Make sure you have [yarn](https://classic.yarnpkg.com/lang/en/docs/install/#mac-stable), you can install it with:
```BASH
npm install --global yarn
```

## To run the app, simply do:
```BASH
yarn run start
```

## To run the app in development mode:
```BASH
yarn run development
```

## To run the app in production mode:
```BASH
yarn run production
```
There is a bug with workspace with production mode, please do not run

## To run test
```BASH
yarn run test
```
